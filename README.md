# HOPE: GA 기반 무선 AP 품질 평가 재분석

이 저장소는 무선 LAN 측정 데이터를 이용해 기존 RSSI 방식, APQI 방식, 그리고 유전 알고리즘(Genetic Algorithm, GA) 기반 HOPE 방식을 비교·분석하는 Python 코드를 제공합니다.

HOPE 방식은 네트워크 상태를 정상과 혼잡으로 구분한 뒤 다음과 같이 점수를 계산합니다.

- 정상 상태: RSSI 기반 점수
- 혼잡 상태: RTT와 채널 사용률(UTIL)의 GA 가중합 점수
- 최적화 기준: 전체 하이브리드 점수와 실제 전송률(`Upload + Download`) 사이의 Pearson 상관계수

## 주요 분석 내용

- RSSI 변화 환경, 혼잡 환경, 혼합 환경 비교
- 기존 RSSI, APQI, GA 기반 HOPE 방식의 성능 비교
- Pearson 상관계수와 Spearman 순위상관계수 계산
- Bootstrap 95% 신뢰구간 산출
- 5-fold 교차검증 및 측정 세션 단위 교차검증
- GA 가중치 탐색 결과를 0.001 간격 전수 탐색으로 검증
- 분석 품질관리(QC), 제외 표본, 행별 산출 결과 저장

## 분석 기준

정상·혼잡 상태는 아래 조건으로 판정합니다.

```text
RTT >= 22 ms 또는 UTIL >= 56%  → 혼잡
그 외                           → 정상
```

GA 점수 입력에는 `RTT_ms`와 `UTIL_percent`만 사용합니다. RSSI, Link 속도, Packet Loss, Upload 및 Download 속도는 GA 가중 점수의 입력에서 제외됩니다. 실제 전송률은 GA 적합도와 최종 성능 평가 기준으로만 사용됩니다.

재현성을 위해 난수 시드는 `42`로 고정되어 있습니다.

### Excel 시트

측정 데이터 파일에는 다음 시트가 필요합니다.

- `NATURAL_1H_R1`
- `OPEN2_1H_R1`
- `OPEN2_20M_R1`
- `FREE1_1H_R1`
- `FREE1_1H_R2`
- `MOVE_OPEN2_1H_R1`
- `MOVE_OPEN2_1H_R2`
- `CONGESTED_OPEN2_R1`
- `CONGESTED_OPEN2_R2`

또한 아래 필수 열을 포함하는 400행 통합 원자료 시트가 하나 있어야 합니다. 코드는 시트 이름이 아니라 행 수와 필수 열을 기준으로 해당 시트를 찾습니다.

### 필수 열

| 열 이름 | 설명 |
|---|---|
| `RSSI_dBm` | 수신 신호 세기 |
| `Link_Mbps` | 링크 속도 |
| `UTIL_percent` | 채널 사용률 |
| `RTT_ms` | 왕복 지연시간 |
| `PacketLoss_percent` | 패킷 손실률 |
| `Upload_Mbps` | 업로드 전송률 |
| `Download_Mbps` | 다운로드 전송률 |

## 데이터 전처리

- 필수 열 가운데 하나라도 비어 있거나 숫자로 변환할 수 없는 행은 제외합니다.
- 코드에 지정된 측정 오류 2행을 제외합니다.
  - `NATURAL_1H_R1`의 Excel 2행
  - `FREE1_1H_R2`의 Excel 2행
- 실측 과정에서 발생할 수 있는 중복값은 임의로 제거하지 않습니다.
- 상황별 9개 시트를 합친 400개 원자료와 통합 원자료 시트가 수치상 일치하는지 확인합니다.

- 연구 결과를 인용하거나 재사용할 때에는 데이터 수집 조건, 제외 기준, 상태 판정 임계값, 교차검증 결과를 함께 확인해 주세요.
